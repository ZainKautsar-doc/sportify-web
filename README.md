# Sportify Web (Frontend)

Sportify Web adalah antarmuka (frontend) dari aplikasi booking lapangan olahraga yang dirancang untuk memberikan pengalaman pengguna yang sederhana, responsif, dan mudah digunakan. Project ini berfokus pada pengembangan UI/UX dan saat ini belum terintegrasi dengan backend (API).

---

## Overview

Aplikasi ini mensimulasikan alur booking lapangan mulai dari pemilihan jadwal hingga proses pembayaran. Seluruh data yang digunakan masih bersifat statis atau mock data sebagai tahap awal pengembangan sebelum integrasi backend.

---

## Fitur Utama

### User Interface
- Tampilan landing page
- Daftar lapangan olahraga
- Halaman detail lapangan

### Booking Flow (UI Simulation)
- Pemilihan tanggal dan waktu
- Form booking
- Ringkasan pemesanan

### Payment (UI Only)
- Tampilan informasi pembayaran
- Simulasi upload bukti pembayaran

### Responsiveness
- Desain responsif untuk desktop dan mobile

## Menjalankan Project

### 1. Clone Repository
```bash
git clone https://github.com/ZainKautsar-doc/sportify-web.git
cd sportify-web
```

---

### 2. Install Dependencies
```bash
npm install
```

---

### 3. Jalankan Aplikasi
```bash
npm run dev
```
